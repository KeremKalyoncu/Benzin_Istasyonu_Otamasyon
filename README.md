## 📋 Hakkında

Bir benzin istasyonunun günlük operasyonlarını yönetmek için geliştirilmiş masaüstü
otomasyon uygulaması. Pompa envanteri, yakıt satışları ve günlük işlem takibini
tek bir arayüzden yönetir.

## ✨ Özellikler

- ⛽ Pompa ve yakıt stok takibi
- 💰 Satış ve işlem kayıtları
- 📊 Günlük operasyon özeti
- 🖥️ Kullanıcı dostu Windows Forms arayüzü

## 🚀 Çalıştırma

**Hazır derleme ile:** Repodaki `.exe` kısayolunu kullanarak doğrudan başlatabilirsiniz.

**Kaynak koddan:**

```bash
git clone https://github.com/KeremKalyoncu/Benzin_Istasyonu_Otamasyon.git
```

1. `WindowsFormsApp1.sln` dosyasını Visual Studio ile açın
2. **Build → Build Solution** (Ctrl+Shift+B)
3. **F5** ile çalıştırın
